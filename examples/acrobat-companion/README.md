# Acrobat Companion Plugin Example

Reference pioneer plugin showcasing window management, companion docking, and dynamic display positioning capabilities in NekoAI.

## Capabilities Used

- `tamagotchi:window-manage`
- `tamagotchi:docking`
- `system:display-info`

## Features

- Centers, minimizes, and aligns client windows.
- Responds to companion position updates.
- Illustrates full lifecycle cleanup hooks.
